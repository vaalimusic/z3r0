# ZERO Feature Discovery — самостоятельное обнаружение признаков компетентности

Добавочный **Rust-бинарник без зависимостей** для существующего проекта ZERO. Скопируйте `src/bin/zero_feature_discovery.rs` в одноимённый путь в проекте.

```powershell
cargo test --bin zero_feature_discovery
cargo run --release --bin zero_feature_discovery -- --seeds 8
```

Автономный запуск: `rustc --edition=2021 -O src/bin/zero_feature_discovery.rs -o zero_feature_discovery`.

## Проверяемая гипотеза

ZERO может, не зная заранее границ применимости инструментов, **выбрать полезный признак и порог из наблюдений**. На каждом тренировочном примере вызваны все четыре неизвестных по названию инструмента; ZERO получает входы `(a,b)`, факт успеха и фактическую стоимость с резервным вызовом. Его модель строится как по одному decision stump на инструмент: самостоятельно выбирает лучший признак из `a,b,min,max,sum,abs_diff,product` и порог по минимуму ошибки оценки полной стоимости. Границы 120 и 160 нигде не передаются в модель.

Это **не** автономное изобретение признаков из произвольных данных: набор семи преобразований задан разработчиком. Мы проверяем самостоятельный *выбор* признака и *обнаружение* границы. Стратегия `fixed_bins` получает прежний заранее выбранный контекст `max(a,b)/40`; `kind_only` не получает числовой контекст. Oracle знает все инструменты и служит оптимистичной границей (стоимость его поиска не учитывается).

## Дизайн

- 2400 обучающих задач, 500 валидационных и 3000 тестовых на каждый seed; независимые случайные последовательности.
- В тесте меняется распределение входов и чаще встречаются значения около порогов, которых модель заранее не знает.
- Обучение без доступа к тестовым данным; нет подбора гиперпараметров по тесту. Валидация только диагностическая.
- Обязательная стоимость неудачных вызовов и резерва X0.
- Все три обучаемые стратегии видят **одинаковые** полные пробные данные. Строки `training_probe_cost` и `training_probe_calls` показывают полную стоимость сбора данных. В `mean_total_cost` входит **только тестовая** стоимость. Для сравнения жизненного цикла прибавляйте стоимость проб к сумме расходов на последующие задачи; полные пробы очень дороги и могут сделать обучение невыгодным.
- Инструменты реализованы реальными арифметическими функциями. Стоимость условная и не равна затраченному процессорному времени. `mean_decision_ns` — диагностическое время выбора, не гарантированно воспроизводимое.

## Отчёты

`reports/zero_feature_discovery/summary.csv`, `learned_features.csv`, `sample_decisions.csv`.

**Критерий успеха:** `discovered` должна превосходить `fixed_bins` по тестовой стоимости, приближаться к Oracle и выбирать разные признаки для инструментов с разными границами. После этого отдельно проверяем окупаемость стоимости проб и перенос на неизвестные инструменты.
